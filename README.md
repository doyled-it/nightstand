# nightstand

Software for a bedside e-ink picture frame (Pimoroni Inky Impression 7.3", Spectra 6) that shows art, what's playing on the house audio, live Padres games, and the morning weather.

The design is in `docs/superpowers/specs/2026-11-06-nightstand-design.md`.

## Part of a multi-repo system

`nightstand` is one of several repos. A feature usually spans repos; before calling
one done, cover its full cross-repo surface (API contract, config/env, deploy,
docs). Start cross-repo work from the hub repo with the siblings cloned. See the
hub's `docs/cross-repo-features.md` and `CONTRIBUTING.md`.
